# PT 추가 내용: 주차 위치 점수 (SVM 연동 확장)

발표자료 7번 슬라이드("주차 위치 점수: SVM 데이터가 열리면 바로 켜집니다")와 함께 쓴다. 발표 1분, 시연 40초, 질의 대비.

## 1. 발표 멘트 (약 60초)

> 지금까지 보신 100점은 "어떻게 주차했는가"를 보는 과정 점수입니다.
>
> 그런데 운전자가 정말 궁금한 건 "내가 칸 안에 반듯하게 세웠나"입니다. 서라운드 뷰 모니터가 있는 차는 이미 차 안에서 주차선을 인식하고 있습니다. 저희는 그 영상이 아니라 **인식 결과 숫자 몇 개**만 요청합니다. 좌우·앞뒤 간격과 기울기, 신뢰도입니다. 얼굴이나 번호판은 들어 있지 않습니다.
>
> 그 숫자가 열리면 위치 점수 100점이 더해지고, 종합 점수는 과정 70%, 위치 30%로 계산됩니다. SVM이 없는 차는 지금처럼 과정 점수만으로 완결됩니다.
>
> 중요한 건 이 기능이 **계획이 아니라 이미 코드로 들어가 있다**는 점입니다. 채점기, 결과 도식, 이력 저장, 단위 테스트까지 끝났고, 남은 건 데이터 소스 하나를 연결하는 일입니다. 지금 가상 데이터로 보여드리겠습니다.

## 2. 시연 (약 40초, 경로 A·B 공통)

| 순서 | 조작 | 말 | 화면 |
| :-- | :-- | :-- | :-- |
| 1 | 대기 화면에서 **SVM 위치 점수 시연** 스위치 켬 | "시연용 가상 데이터입니다. 화면에도 그렇게 표시됩니다." | 스위치 아래 황색 "가상 데이터 · SVM API 제공 전 시연용" |
| 2 | 모범 주차 실행. A는 `scripts/vc.sh model` 또는 Virtual Console 수동 조작, B는 "모범 주차 재생" | (기존 코칭 멘트 그대로) | 기존 코칭 흐름 |
| 3 | P 체결 후 결과 화면 | "왼쪽이 종합, 가운데가 과정, 오른쪽이 위치입니다. 칸과 차를 위에서 본 그림에 네 방향 간격이 나옵니다." | 종합 점수, "과정 n점 · 위치 m점", 위치 도식 |
| 4 | (시간 여유 시) 초보 주차 실행 | "차 앞이 입구선을 넘으면 빨간색으로 표시되고 깊이 점수가 0점이 됩니다." | 빨간 차량, 입구선 −6cm |
| 5 | 주차 이력 열기 | "이력에도 과정과 위치가 따로 남고, 가상 데이터 표시가 붙습니다." | 행마다 "과정 · 위치 · 가상 데이터" |

* 기존 4분 대본에 넣을 위치: "1:50 결과 화면" 직후. 시간이 부족하면 3번까지만 한다.
* 스위치를 켜 둔 채 기존 시연을 하면 결과 화면이 3단으로 바뀐다. 기존 흐름만 보여 줄 때는 스위치를 끈다.

## 3. 예상 질문과 답변

**Q. 실제로 Pleos가 그 데이터를 줄 수 있나요?**
SVM과 원격 스마트 주차 보조가 있는 차량은 주차칸 인식을 이미 하고 있습니다. 저희는 새 센서가 아니라 기존 인식 결과의 공개를 요청하는 것입니다. 데이터 형식은 기획서 5.5절에 표로 정리했습니다.

**Q. API가 없으면 화면을 캡처해서 인식하면 되지 않나요?**
에뮬레이터에서 직접 검토했습니다. 캡처 자체는 가능해 보였지만 세 가지 이유로 배제했습니다. 행인 얼굴과 번호판이 찍히는 개인정보 문제, 주차할 때마다 화면 캡처 동의를 받아야 하는 문제, 차종과 OTA마다 카메라 화면 구성이 바뀌는 문제입니다. 그래서 영상이 아닌 인식 결과만 요청하는 방식을 택했습니다.

**Q. 가상 데이터라면 지금 점수는 의미가 없지 않나요?**
맞습니다. 위치 점수 값 자체는 시연용이고 화면과 이력에 그렇게 표시됩니다. 보여드리는 것은 데이터가 들어왔을 때의 채점 규칙, 화면, 저장 흐름이 이미 동작한다는 점입니다. 운영 빌드의 기본값은 꺼짐입니다.

**Q. 왜 과정 70, 위치 30인가요?**
이 앱의 목적은 습관 교정입니다. 결과가 우연히 좋아도 과정이 나쁘면 다음 주차가 불안정합니다. 가중치는 설정값 한 곳에 있어 실차 데이터로 조정할 수 있습니다.

**Q. 인식이 틀리면 억울한 감점이 생기지 않나요?**
신뢰도가 0.6 미만이면 위치 점수를 아예 표시하지 않습니다. 과정 점수만 남습니다.

**Q. 실시간으로도 쓸 수 있나요?**
인식 결과가 실시간으로 오면 직진 후진 구간에서 "왼쪽으로 치우쳤습니다" 같은 위치 기반 음성 코칭을 추가할 계획입니다. R 구간은 플랫폼이 서드파티 화면을 막기 때문에 음성으로 전달합니다.

## 4. 사전 점검
* release APK 재설치 후 스위치가 **꺼진 상태**로 시작하는지 확인. 앱을 다시 시작하면 꺼짐으로 돌아간다.
* 스위치를 켠 뒤 모범 주차 한 번으로 결과 3단 화면이 나오는지 리허설.
* 음성: 위치 점수가 있으면 "종합 점수는 n점, 주차 위치 점수는 m점입니다"로 한 번에 안내된다.
