# PT 시연 대본 (약 4분)

두 경로 중 하나로 시연한다. 두 경로 모두 동일한 화면 흐름을 만든다.

* **A. Pleos Connect AVD + Virtual Console** (권장, 심사 기준 "Pleos SDK 활용" 직접 증명)
* **B. 임의 Android 에뮬레이터 + 내장 시뮬레이터** (AVD 문제 시 즉시 대체)

## 사전 준비

1. `adb install -r apk/6학년5반_나는야주차왕_release.apk`
2. 앱 실행 → 권한 허용(AVD) → 상단 칩이 **Pleos Vehicle SDK**(A) 또는 **시뮬레이션 모드**(B)인지 확인.
3. 음성 안내 켬 상태 확인, 볼륨 확인.
4. A의 경우 터미널에서 `adb forward tcp:8088 tcp:8088` 실행 후 브라우저로 `http://127.0.0.1:8088/` 에 접속해 Virtual Console을 두 번째 모니터에 띄우고, **Emulation Controls → Motion** 카드(Gear Selection P/R/N/D, Brake Pedal 0~100%, Steering Angle −540~540°)와 **Convenience** 카드(Trunk / Frunk Position)를 열어 둔다. (에뮬레이터 v2.1.0 이상 필요)

## 실패 대비

* AVD에서 조향각이 갱신되지 않으면: 앱을 재시작해 권한 허용 여부 확인 → 그래도 안 되면 경로 B로 전환(앱은 Vehicle Service가 없을 때만 시뮬레이션으로 자동 전환되므로, B는 일반 에뮬레이터에서 실행한다).
* 음성이 안 나오면: 상단 "음성 안내" 토글 확인 → 에뮬레이터 볼륨 확인. 화면만으로도 흐름이 전달되도록 지시문이 항상 표시된다.
* 결과 카드가 안 뜨면: R 상태에서 **속도가 0이 아닌 구간이 2초 이상** 있었는지 확인(이동 없는 R→P는 주차 시도로 집계하지 않음).
