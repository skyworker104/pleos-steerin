# 기획 v5 기술 검토 보고서 (2026-11-08)

공모전 1차 접수(11/15) 전 기획서 v5·README·AI 코딩 명세서 v1을 Pleos 공식 문서, Vehicle SDK 2.3.2 AAR, 공식 샘플 저장소, 공모전 공고 정리 자료와 교차 검증한 결과와 그에 따른 설계 변경 기록이다.

## 1. 결론

아이디어(조향각 기반 후진 주차 코칭 + Snap-In UI)는 심사 1순위 항목인 **차량특화성·기술 활용성**에 정확히 맞는다. 그러나 v5 기획서는 **존재하지 않거나 서드파티 앱이 받을 수 없는 데이터**를 핵심 기능의 전제로 삼고 있어 그대로 제출하면 기술 심사에서 바로 지적당할 구조였다. 따라서 데이터 경로·평가 체계·핵심 알고리즘 정의를 전면 교체했다.

## 2. v5의 기술 전제 오류

| # | v5 내용 | 검증 결과 | 영향 |
| :-- | :-- | :-- | :-- |
| 1 | `GET /v1/vehicles/{vin}/locations` 등 **Pleos Vehicle Data API** + OAuth 2.0 | 클라우드 REST API. 외부 서비스용, **2026년 8월 기준 유럽에서만 제공**, 실시간 스트림 아님 | 차량 내 앱 아키텍처로 성립 불가 |
| 2 | `Vehicle.checkSupport()`, `VehicleProperty.STEERING_WHEEL_ANGLE`, `SensorRate.FAST` | 실존하지 않는 API. 실제는 `Vehicle(context).initialize()` → 도메인 객체 → `checkXxxCapabilities/getCurrentXxx/registerXxx` 비동기 콜백 | 코드 예시 신뢰도 상실 |
| 3 | `Pleos_Connect_v2.1` = SDK 버전 | AVD 이름. SDK는 2.3.2, Vehicle Service 2.3.13+ | 용어 오류 |
| 4 | 초음파 센서 경고 단계 (20점) | Vehicle SDK Safety 도메인은 텔테일·안전벨트·에어백 수준. PDW 거리 API 없음. ADAS SDK는 미공개 | 20점 항목 근거 없음 |
| 5 | 위경도·방위각으로 중앙 정렬 10 cm/2점 (30~40점) | FusedLocation SDK는 차종별 상이·준비 중. GPS는 미터급. 정차 상태 방위각 신뢰 불가 | 40점 항목 측정 불가 |
| 6 | 후방 카메라 궤적선으로 목표 조향각 산출 | 서드파티 앱에 카메라 접근 경로 없음 | **핵심 기능 정의 공백** |
| 7 | Gleo AI 음성 연동 | 서드파티 연동 문서 없음 | TTS SDK/Android TTS로 대체 |
| 8 | 가속 페달 위치 | 공개 도메인에 없음 | 차속 미분으로 대체 |
| 9 | 블루핸즈 할인·UBI 보험료 할인 "보상 체계" | 2인 일반팀이 약속할 수 없는 제3자 혜택. 사업성 항목(타깃·MAU·리텐션)에 수치 없음 | 사업성 근거 부재 |
| 10 | "국내 운전 환경의 90% 이상이 후진 주차", APJCRI·PNAS 연구 | 출처 없음 | 삭제 |

## 4. 설계 변경

1. **데이터 경로**: Vehicle Data API 폐기 → Vehicle SDK(온디바이스) + AAOS Car API. Maven `nexus-playground.pleos.ai`는 인증 없이 공개되어 있어 외부 빌드가 가능하다.
2. **평가 체계**: "주차 칸 대비 정밀 위치"에서 **"주차 과정 품질"**로 피봇. 조향 안정성 35 / 재시도 25 / 속도·제동 20 / 안전 10 / 시간 10. 모든 항목이 가용 신호 위에 있다. (`docs/SCORING.md`)
3. **Ghost 목표각**: 운동학 자전거 모델로 조향각·차속을 적분해 **상대 회전량**을 추정하고, 직각 후진 표준 절차(풀 록 → 70° → 88° 직진)로 단계별 목표각을 낸다. GPS·카메라·주차 칸 정보가 필요 없다.
4. **안전 UX**: R 기어에서 시스템 후방 카메라가 센터 화면을 점유할 수 있고, 후진 중 센터 화면 주시는 Driver Distraction 관점에서 불리하다. 음성을 주 채널로, 링은 확인용으로 재정의하고 `CarUxRestrictionsManager`를 연동했다.
5. **사업성**: 외부 보상은 제휴 전제의 로드맵으로 강등. 타깃·MAU·리텐션을 가정치와 산식으로 명시.
6. **문서 위생**: 심사 자료 익명성 지침에 따라 실명 제거, 패키지명 `com.steerin.parkingmaster`로 통일, 출처 없는 통계 삭제.

## 5. 남은 리스크

* Pleos AVD에서 조향각 콜백 **주기와 분해능**을 아직 실측하지 못했다(튜토리얼 주석에 50° 변화 임계 언급). 3~5° Snap-In 허용 오차가 성립하지 않으면 폴링 보완 또는 허용 오차 조정이 필요하다.
* 조향각 **부호**(+가 우측인지)를 AVD에서 확인해야 한다.
* R 기어 시 서드파티 앱이 포그라운드를 유지할 수 있는지(후방 카메라 뷰와의 관계)는 Pleos Connect 실기기에서만 확정된다. 멀티윈도우 또는 음성 중심 폴백을 준비해야 한다.
* Pleos Connect AVD 시스템 이미지는 Playground 신청 후 제공된다. 본 저장소의 앱은 Vehicle Service가 없으면 내장 시뮬레이터로 자동 전환되므로 일반 에뮬레이터에서도 전체 흐름을 시연할 수 있다.
